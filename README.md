Landing page estática. Os arquivos publicados estão em `dist/`.

## Visualizar
```sh
npm run dev
```
Abra http://127.0.0.1:4173.

## Editar
- Conteúdo e links: `dist/index.html`.
- Layout: `dist/styles.css`.
- Menu e temas: `dist/app.js`.
- Fotos provisórias: `dist/assets/conferencia.webp`, `conexoes.webp`, `gestao.webp`, `encontro.webp`.
- Evento na agenda: `dist/conecta.ics`.
- Pesquisa, fontes e divergência de horário: `REFERENCIAS.md`.

Compra leva a https://conectacnpjotas.com/. Interesse em patrocínio leva a https://conectacnpjotas.com/patrocinio.
